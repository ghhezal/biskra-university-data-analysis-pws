# Biskra University Data Analysis PWs

Practical works completed for the **Data Analysis** module during **Master 1 in Computer Science at Biskra University**.

This repository contains the exercises and notebooks completed throughout the module, mainly using Python for data exploration, visualization, cleaning, correlation analysis, and statistical methods.

## Practical works

### PW1: Introduction to Data Analysis with Python

Covers the basics of working with data in Python, including:

- dataset inspection
- descriptive statistics
- frequency analysis
- histograms and boxplots
- outlier detection using IQR
- missing values
- duplicate detection
- scatter plots
- correlation analysis
- group analysis

### PW2: Analysis of Relationships Between Variables

Covers statistical methods used to study relationships between variables, including:

- Pearson correlation
- Spearman rank correlation
- Chi-square test of independence
- one-way ANOVA

More details for each practical work are available inside its own folder.

## Stack

Python, NumPy, Pandas, Matplotlib, Seaborn, SciPy
